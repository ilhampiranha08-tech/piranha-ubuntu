## 📖 Sinopsis Jilid 1

Di Desa Panggungharjo, seorang anak berhoodie merah bernama **Riko** mengalami masalah saat laptopnya mati total dan menampilkan pesan *"No OS Found"*. Kemunculan **Tux si Pinguin** membimbing Riko mengenal dunia sistem operasi bebas Linux Ubuntu.

Petualangan membawa mereka menghadapi monster bug di terminal, menerobos proteksi izin folder `/root` menggunakan kekuatan sakti `sudo`, terbang ke stasiun antariksa, mendirikan **Lab Komunitas Ubuntu** di desa, hingga akhirnya menemukan *Jantung Repositori Open Source* di gua tersembunyi dan membebaskan kode sumber untuk seluruh dunia.

## 📑 Daftar 10 Bab & Materi Pembelajaran

| Bab | Judul Chapter | Topik Pembelajaran Linux |
| :---: | :--- | :--- |
| **01** | **Kode Pertama** | Mengatasi *"No OS Found"*, pengenalan OS bebas & instalasi Ubuntu. |
| **02** | **Petualangan di Terminal** | Membuka CLI, `sudo apt update`, dan mengatasi paket rusak dengan `sudo apt upgrade --fix-broken`. |
| **03** | **Boss di Folder Root** | Struktur direktori Linux, folder `/root`, izin akses (*Permission Denied*), dan kekuatan admin via `sudo`. |
| **04** | **Petualangan Luar Angkasa** | Debugging logika dan teknik live-patching modul sistem di terminal. |
| **05** | **Misi Baru di Bumi** | Pemanfaatan komputer lawas dengan Ubuntu 24.04 LTS & mendirikan Lab Komunitas Desa. |
| **06** | **Festival Ubuntu 2026** | Inovasi IoT: *Piranha Ubuntu Bot* untuk pemantauan kualitas danau real-time ke cloud. |
| **07** | **Petualangan Hutan Piranha** | Sensor Ubuntu tenaga surya untuk konservasi ekosistem sungai berkelanjutan. |
| **08** | **Setelah Hutan Piranha** | Pembangunan server pemantau mandiri energi (Green Data Center / 100% Solar) aktif 24/7. |
| **09** | **Pulau Kode 9** | Server kuno tahan banting (*Ubuntu Server 26.04 LTS*) & kriptografi pemecahan kunci. |
| **10** | **Final Repository Tersembunyi** | Pelepasan seluruh kode sumber (`piranha_core.cpp`, `utils.go`) di bawah lisensi terbuka **GPL-3.0**. |

## 💻 Folder Kode Praktek Jilid 1

Semua kode dan simulasi dari cerita Jilid 1 dapat dicoba langsung di folder [`code-examples/`](code-examples/):
* `01_kenalan_terminal.sh` — Belajar perintah dasar terminal Linux (`whoami`, `uname`, `pwd`, `df -h`).
* `02_update_dan_upgrade.sh` — Simulasi penanganan bug dengan manajer paket `apt`.
* `03_sudo_dan_permissions.sh` — Demonstrasi proteksi folder `/root` dan peran `sudo`.
* `04_sensor_ekosistem_piranha.py` — Simulasi telemetri sensor sungai & panel surya hijau.
* `piranha_core.cpp` — Kode C++ mesin utama yang diunggah di Bab 10.
* `utils.go` — Utilitas Go telemetri & verifikasi kunci `OPEN_SOURCE_2026`.
