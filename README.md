## 📑 Ikhtisar Pembelajaran Serial

### 📘 [Jilid 1: The Complete Saga (10 Bab)](jilid-01/)
1. **Bab 1:** Mengatasi *"No OS Found"* & Pengenalan Instalasi Ubuntu.
2. **Bab 2:** Perintah Terminal Pertama (`sudo apt update` & `--fix-broken`).
3. **Bab 3:** Monster Folder `/root`, Proteksi Hak Akses, dan Mantra `sudo`.
4. **Bab 4:** Petualangan Antariksa & Live-Patching Bug Navigasi.
5. **Bab 5:** Membangun Lab Komunitas Desa dengan Ubuntu 24.04 LTS.
6. **Bab 6:** Festival Ubuntu & Bot Pemantau Danau Real-Time ke Cloud.
7. **Bab 7:** Sensor Kualitas Air Mandiri Surya di Hutan Piranha.
8. **Bab 8:** Pusat Data Hijau 24/7 Ramah Lingkungan & Mandiri Energi.
9. **Bab 9:** Server Kuno Ubuntu Server 26.04 LTS & Kunci Kriptografi `OPEN_SOURCE_2026`.
10. **Bab 10:** Jantung Repositori Tersembunyi & Pelepasan Kode (`piranha_core.cpp`, `utils.go`) Lisensi GPL-3.0.

### 📙 [Jilid 2: Petualangan Jaringan, Container & Keamanan Siber](jilid-02/)
*(Dalam tahap perancangan naskah & konsep cerita)*  
Mencakup materi menengah: Konsep Jaringan Linux (`ip`, `ping`), Remote Access aman (`ssh`), Pertahanan Firewall (`ufw`), Isolasi Aplikasi (**Docker**), Otomasi Script Bash & Cron, serta Kolaborasi Tim via GitHub.
