# Panduan Kontribusi — Piranha Ubuntu 🐟🐧

Terima kasih atas ketertarikan Anda untuk berkontribusi pada proyek edukasi terbuka **Piranha Ubuntu**! Proyek ini menjunjung tinggi semangat gotong royong dan filosofi Open Source.

---

## 🤝 Cara Anda Bisa Berkontribusi

Ada banyak cara untuk ikut bergotong royong dalam proyek ini:

1. **Penerjemahan (Lokalisasi / i18n):**
   * Menerjemahkan naskah cerita dan dialog ke dalam Bahasa Inggris atau bahasa daerah Indonesia (seperti Bahasa Jawa, Sunda, dll.).
2. **Pengembangan Materi & Skrip Latihan:**
   * Menambahkan contoh skrip bash, python, atau panduan praktikum Linux yang cocok untuk anak-anak dan pemula di folder `code-examples/`.
3. **Penyempurnaan Web Reader:**
   * Memperbagus fitur pembaca komik di `index.html` (misalnya menambahkan mode zoom, navigasi sentuh yang lebih mulus, dll.).
4. **Distribusi & Edukasi:**
   * Menggunakan dan membagikan materi ini di sekolah, pesantren, lab komunitas, atau kelompok belajar komputer di desa Anda.

---

## 🚀 Alur Kerja Kontribusi (Pull Request)

1. *Fork* repositori ini ke akun GitHub Anda.
2. Buat *branch* fitur baru:
   ```bash
   git checkout -b fitur/terjemahan-english
   ```
3. Lakukan perubahan dan commit:
   ```bash
   git commit -m "feat: Menambahkan terjemahan bab 1 ke bahasa Inggris"
   ```
4. Push ke branch Anda:
   ```bash
   git push origin fitur/terjemahan-english
   ```
5. Buat **Pull Request (PR)** baru di GitHub.
